# apzbot

Telegram Mini App for laundry booking.

## Project Structure

- `backend/`: Node.js server and Telegram bot logic.
- `frontend/`: HTML/CSS/JS for the Mini App interface.

## Quick Start

### Backend
1. `cd backend`
2. `npm install`
3. Configure `.env`
4. `node db/init_db.js`
5. `npm start`

### Frontend
The frontend consists of static files that can be served directly or through the backend.
